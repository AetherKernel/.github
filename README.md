# AETHER Kernel

**Civic and health tech, built in Lima, Peru.** We are Kiara, Alexis and José, building
digital products for problems close to home: neighborhood safety and health care at home. We build in public and
only talk about what already works.

| Project | What it is | Status |
|---|---|---|
| [**Vecino Seguro**](https://www.vecinoseguro.tech) | Civic safety web platform | Public beta |
| [**AXONFAS**](https://github.com/AetherKernel/AXONFAS) | Home physiotherapy supervised by the clinic | Prototype, AMD Developer Hackathon ACT III (Oct 2026) |
| [**SIGNO**](https://github.com/AetherKernel/SIGNO) | Tells real change from noise in the Amazon with NASA satellite data | NASA Space Apps Challenge 2026, Lima |
| [**LabLens**](https://github.com/AetherKernel/LabLens) | Medical document scanner: take a photo with your phone and get the document straightened and flat | In development |

**How we build:** demo data before real data · AI helps, but never makes the safety-critical call · small, honest updates.
